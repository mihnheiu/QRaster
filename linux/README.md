# 🐧 QRaster - Linux Desktop Application

This directory contains the native Linux desktop application built with Python 3 & Tkinter.

## 🚀 Running the Linux App

Run directly with Python:
```bash
python3 main.py
```
Or execute `run.sh`:
```bash
chmod +x run.sh
./run.sh
```

## 📦 Building Standalone Executable

Run `build.sh` to create a Linux executable using PyInstaller:
```bash
chmod +x build.sh
./build.sh
```

For full project documentation, technical details, and user guide, see the [Root README.md](../README.md).
