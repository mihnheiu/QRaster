# 🪟 QRaster - Windows Desktop Application

This directory contains the native Windows desktop application built with Python 3 & Tkinter.

## 🚀 Running the Windows App

Run directly with Python:
```cmd
python main.py
```
Or double-click `run.bat`.

## 📦 Building Standalone `.exe`

Run `build_exe.bat` to create a standalone Windows binary using PyInstaller:
```cmd
build_exe.bat
```

For full project documentation, technical details, and user guide, see the [Root README.md](../README.md).
