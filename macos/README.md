# 🍎 QRaster - macOS Desktop Application

This directory contains the native macOS desktop application built with Python 3 & Tkinter.

## 🚀 Running the macOS App

Run directly with Python:
```bash
python3 main.py
```
Or execute `run.sh`:
```bash
chmod +x run.sh
./run.sh
```

## 📦 Building Standalone `.app`

Run `build_app.sh` to create a macOS application bundle using PyInstaller:
```bash
chmod +x build_app.sh
./build_app.sh
```

For full project documentation, technical details, and user guide, see the [Root README.md](../README.md).
